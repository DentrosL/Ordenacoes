# ordenações
> implementação "didática" de algoritmos de ordenação em Python.

este projeto apresenta, de forma simples, como diferentes algoritmos organizam
uma lista de números em ordem crescente. ao executar o programa, é possível
escolher o algoritmo pelo menu e visualizar o resultado da ordenação.

## algoritmos disponíveis
- bubble sort
- quick sort
- insertion sort
- selection sort
- merge sort

## como executar
é necessário ter o Python 3.10 ou uma versão mais recente, pois o programa
utiliza `match`/`case`.

no terminal, dentro da pasta do projeto, execute:
```bash
python main.py
```
depois, escolha uma opção do menu:
```text
1. bubble sort
2. quick sort
3. insertion sort
4. selection sort
5. merge sort
6. sair
```
## estrutura
- `main.py`: menu e implementações dos algoritmos de ordenação.
